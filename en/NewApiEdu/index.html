NewApi Edu

Repository
Welcome, friends with some free time, to come and play together.

Introduction

The origin of this project: after my hemorrhage, I discussed with a buddy about trying to be a token middleman to earn some extra cash. Later we found it hard to pull off. As I was learning AI, I increasingly felt the huge potential of AI, so I thought about whether I could do something to help the students still in school keep up with this era more easily. And so this project was born.
A university-customized version based on NEWAPI — an AI API gateway and AI asset management platform.

University-Customized Features

  • Campus identity authentication (completed): supports student ID / staff ID login
  • Course management (planned): allocate AI usage permissions by course
  • Teacher management (planned): teachers manage their class’s students
  • Teaching statistics (planned): AI usage data analysis
  • Security audit (planned): operation logs and auditing
  • Campus network adaptation (planned): intranet optimization, proxy/firewall

**Why is so much still “planned”? Because I don’t know what counts as good either — after trying it myself, I feel it’s about there.

  1. Since I’m unemployed with no income, the early tokens all came from new-user quotas and invitation bonuses from various platforms. Because setting up a stage for AI (preparing test environments and data for AI also requires AI to do part of it — I’m already a salted fish now),
    Thanks to DeepSeek. I topped up 400 as a token of support (haven’t even used half of it yet, trying to save as much as possible — I always try to use the free quota first).
  2. Mr. Lei’s 10-billion welfare — didn’t manage to apply for it.
  3. No complete university or enterprise environment for testing. I don’t know what to vibe or which systems to integrate with.
  4. I have to go to the hospital every day, so I don’t have enough time in front of the computer.

Tech Stack

Layer Technology
Backend Go + Gin + GORM
Frontend React 18 + Vite 5 + Semi Design
Database SQLite / MySQL / PostgreSQL
Cache Redis
Auth JWT / OAuth / LDAP
i18n zh / en / fr / ja, etc.
