服务器硬件信息

获取主机硬件信息：

  • cpu: CPU 信息
  • ipmi: IPMI 信息
  • smartcard: Smart card 子系统
  • usb: VMware USB Plugin
  • bootdevice: Boot device 信息
  • clock: 硬件时钟交互
  • memory: 内存信息
  • pci: PCI 设备信息和配置
  • platform: 平台信息
  • trustedboot: Trusted Boot 状态信息

监控

esxtop

类似 Linux top，切换热键：

  • C (CPU)
  • I (interrupt)
  • M (memory)
  • N (network)
  • D (disk adapter)
  • U (disk device)
  • V (virtual disk)
  • P (power mgmt)
